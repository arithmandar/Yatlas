# Yatlas

A minimap-based world map browser for World of Warcraft.

Yatlas provides a browsable view of the world using minimap terrain imagery,
offering a different perspective from the game's illustrated world maps.

## Project Status

Yatlas is being moved to GitHub as a first step toward bringing the addon
back into working order.

The initial goal is to assess the existing code and determine what is needed
to restore compatibility with current WoW clients.

This is not yet a compatibility release. The source code and historical
downloads should not be assumed to work with current clients.

Supported clients and installation instructions will be documented as
compatibility is verified.

## Downloads

Historical releases are available on
[CurseForge](https://www.curseforge.com/wow/addons/yatlas).

These releases predate the planned compatibility work and may not function
with current WoW clients.
